# CLAUDE.md — контекст мобильной версии

## Что это
Flutter-приложение игры «Туман Владивостока» (Android + iOS). Логика перенесена из веб-прототипа,
который лежит рядом в `../vl-fog` (чистые ES-модули) — там же `CONCEPT.md` с описанием игры.
Главное, ради чего делали мобилку: GPS работает с выключенным экраном, туман открывается,
пока телефон в кармане.

## Запуск и проверка
- `flutter run -d <id>` на телефоне; `flutter build apk --debug` + `flutter install -d <id>`
  (`flutter install` сам НЕ пересобирает).
- `flutter test` — 8 тестов: совместимость ключей тумана с веб-версией, прохождение сюжетной
  миссии, слежка (успех и провал), кодирование кэша улиц.
- Веб-сборка (`flutter build web`) удобна для быстрой проверки интерфейса в браузере,
  но GPS в фоне так не проверить.
- Телефон: `adb devices`, снимок экрана — `adb shell screencap -p /sdcard/s.png` + `adb pull`
  (перенаправление `adb exec-out` в PowerShell портит бинарный файл).

## Архитектура
- `lib/core/geo.dart` — расстояния, азимуты, сетка тумана. **Ключи ячеек `"row:col"` совпадают
  с веб-версией** (есть тест), чтобы можно было перенести прогресс.
- `lib/core/storage.dart` — `Store`: мелкое в SharedPreferences, крупное (туман, кэш мест и улиц)
  в файлы; `Store.inMemory()` для тестов, `Debouncer` для отложенной записи.
- `lib/game/` — логика без виджетов: `fog`, `player`, `poi`, `route`, `districts`, `quests/`.
  `hud.dart` — состояние интерфейса, которым управляет игра (реплики, баннеры, карточка задания).
- `lib/map/` — слои карты: `basemap` (стиль + тайлы), `fog_layer` (CustomPainter), `quest_layers`
  (метки, пунктир к цели), `tile_cache*` (папка файлового кэша, условный импорт).
- `lib/ui/` — экран и оверлеи: `game_screen` (игровой цикл на Ticker), `overlays`, `radar`, `widgets`.
- Игровой цикл: `Ticker` → `game.tick(dt)`; все таймеры и NPC считаются в игровом времени
  (`dt * player.timeScale`, в симуляции ×8).

## Карта
- Векторные тайлы OpenFreeMap (без ключа) + `flutter_map` 8 и `vector_map_tiles` 9 (бета —
  стабильной версии под flutter_map 8 нет).
- Стиль `assets/map/style.json` — копия из веб-версии, собирается `../vl-fog/tools/build-map-style.py`
  (перекрашенный «dark», подписи `name:ru`, без границ/стран/регионов). **После пересборки стиля
  скопировать файл сюда.**
- Тайлы кэширует сам `vector_map_tiles` в постоянной папке (`tile_cache_io.dart`), 200 МБ, 60 дней.

## Android
- `applicationId` — `ru.vlfog.game`. Разрешения на геопозицию, foreground-сервис и уведомления
  прописаны в `android/app/src/main/AndroidManifest.xml`, включая `INTERNET`
  (в шаблоне Flutter он есть только в отладочной сборке).
- Фоновый GPS: `geolocator` с `ForegroundNotificationConfig` → сервис с типом `location`.
  На Android 13+ нужно разрешение на уведомления, его просит `player.dart` при включении GPS.
- `permission_handler` держим на 12.x: с 13.0.2 подтягивается `permission_handler_android` 14,
  которому нужен compileSdk 37, а Flutter 3.44 собирает с 36 (`checkDebugAarMetadata` падает).
  Поднимать SDK ради одного разрешения не стали.
- `kotlin.incremental=false` в `android/gradle.properties`: иначе на Windows сборка падает с
  «Could not close incremental caches», когда проект и кэш пакетов на разных дисках.

## Соглашения
- Весь пользовательский текст на русском. Реплики — «Имя: текст», имя подсвечивается золотым.
- Генераторы квестов отдают «сырой» Map с id точек, `resolveQuest()` его проверяет
  (schema.dart) — общий контракт с веб-версией и с будущей локальной моделью.
- Автор в РФ: в интерфейсе не должно быть украинской символики. Проверять подписи карт и
  сторонних библиотек после обновлений.

## Что дальше
1. **Прогулка с выключенным экраном не проверена на улице** — сервис поднимается, но реальную
   прогулку надо пройти ногами.
2. **Локальная модель (Ollama)** не перенесена: на телефоне `localhost` — сам телефон, нужен
   адрес компьютера в сети и разрешение на открытый http (`usesCleartextTraffic`).
3. **Линия к цели прямая** — можно вести по `walkRoute()`, как ходит NPC.
4. **Синхронизация прогресса** между устройствами (Supabase) и перенос сохранения из веб-версии.
5. **Иконка** сгенерирована из веб-версии; для магазина нужна своя, более выразительная.
6. **Релизная сборка** не настроена: нужен ключ подписи и `flutter build apk --release`.
